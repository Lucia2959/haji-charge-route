# 경로 최적화 · 충전소 추천 로직 검토 (Route Optimization Review)

작성일: 2026-07-30 · 대상: `haji-charge-route` 충전 계획 계산

---

## 1. 기존 로직의 결함

기존 `plan_charge_stops`는 **출발지 기준 고정 간격**으로 충전 지점을 찍었다.

```
1차 충전 = (현충전량% − 10%) × 유효거리/100          # 출발지로부터 고정
2차 = 1차 + (80% − 10%) × 유효거리/100               # 이후 동일 간격 반복
...
그리고 각 고정 지점 '이전'의 가장 가까운 충전소를 별도로 매핑
```

**문제점**

| # | 결함 | 결과 |
|---|------|------|
| 1 | 충전 지점을 **추상 거리(간격)** 로 잡고, 충전소는 그 근처를 나중에 매핑 | 추천된 충전소들이 **실제로 서로/목적지까지 도달 가능한 사슬(chain)** 을 이루지 못함 |
| 2 | 간격을 **출발지 기준**으로 누적 → 실제 선택된 충전소 위치와 어긋남 | 예: 1차 충전소가 80km에 있으면 2차 기준은 80km에서 다시 계산돼야 하는데, 고정 105km+간격을 사용 |
| 3 | 도달 가능성(reachability) 미검증 | 50%로 출발했는데 **1차 충전을 369km에 배치**(도달 불가) 하는 사례 발생 |
| 4 | 도착지에도 충전점을 찍음 | 무의미한 충전 지점 |

즉 "현재 충전 상태로 갈 수 있는 거리"만 계산할 뿐, **경로를 따라가며 실제 충전소로 완주 가능한 계획**을 세우지 못했다.

## 2. 타 EV 경로 플래너의 계산 로직 (조사)

### A Better Route Planner (ABRP) — 업계 표준
- **소비 모델**: 주행거리는 속도·기온·적재·교통·고도·충전커브·배터리 상태에 따라 변한다.
- **충전 정지 산정**: 다음 충전소에 **사용자가 지정한 도착 잔량(buffer)** 으로 도달하는 데 필요한 kWh만 충전 → 필요한 충전 시간 산출.
- **시간 최적화**: 충전은 SoC가 높을수록 느려지므로(충전 커브 taper), **각 충전소에 최소한의 편안한 잔량으로 도착**하는 것이 전체 시간 최소.
- **사용자 컨트롤**: 충전 간 최저 SoC, 목적지 도착 SoC.

### Tesla Trip Planner
- 경로상 슈퍼차저를 제안, **다음 충전소까지 도달 + 버퍼**만큼만 충전, 전체 시간 최소 지향(보통 80% 부근에서 정지 — 충전 커브).

### 학술/일반
- 대규모 충전소 경로는 **그래프 최적화**(예: Kinetica-Graph, arXiv 2206.06241)로 풀지만,
- 실무 baseline은 **greedy "최대 도달가능(farthest-reachable)"** — 도달 가능한 가장 먼 충전소를 선택해 정지 횟수를 최소화하면서 도달가능성을 보장.

**출처**
- ABRP: https://abetterrouteplanner.com/ , https://github.com/A-Better-Routeplanner
- ABRP 충전 로직 설명: https://www.rivianownersforum.com/threads/how-does-abrp-calculate-charge-times.4797/
- EV 충전 경로 최적화(논문): https://arxiv.org/pdf/2206.06241
- 기온 영향(Geotab/AAA), 속도-공기저항(Geotab): 별도 `charging.py` 주석 참조

## 3. 새 로직 — 경로 기반 Greedy (도달가능성 보장)

`recommend_charging_stops()` (backend/app/services/charging.py)

### 3.1 파라미터
- **유효거리** `R_eff` = 정격 300km × 온도계수 × 속도계수 (기존 외부환경 보정 유지)
- **안전마진(도착 버퍼)** `reserve` = 10% (ABRP의 arrival buffer 개념)
- **충전 목표** `charge_to` = 80% (충전 커브 taper → 시간 효율, Tesla/ABRP 관례)
- `km_per_pct` = R_eff / 100
- `usable_now` = (현재% − 10%) × km_per_pct — 현충전량 도달가능 거리
- `range_after_charge` = (80% − 10%) × km_per_pct — 1회 충전 후 도달가능 거리

### 3.2 충전소 투영
경로 좌표열에 각 충전소를 투영 → `(경로누적거리 c, 이탈거리 o, 충전소)`, `o ≤ 8km(detour)`만 후보.

### 3.3 Greedy 진행 (핵심)
```
pos = 0, range_left = usable_now
while pos + range_left < 목적지거리:            # 아직 목적지 도달 불가
    후보 = { 충전소 | c > pos 그리고 (c − pos) + o ≤ range_left }   # 진행방향 + 이탈 포함 도달가능
    if 후보 없음: feasible = False; break        # 완주 불가
    선택 = 후보 중 '가장 멀리(c 최대)', 그 15km 밴드에서 급속·근접 우선
    충전지점 추가(선택)
    pos = 선택.c
    range_left = range_after_charge − 선택.o     # 경로 복귀분 차감
```
- **도달가능성 보장**: 각 충전소는 직전 위치에서 실제로 갈 수 있는 것만 선택. 마지막 충전 후 `pos + range_left ≥ 목적지`가 되면 종료.
- **정지 최소화**: 매 단계 가장 먼 도달가능 충전소 선택(greedy).
- **충전시간 절감**: 최원거리 15km 밴드 내에서 **급속(DC) 충전기 우선**, 이탈거리 짧은 곳 선호.
- **완주 불가 판정**: 도달 가능한 충전소가 없으면 `feasible=False` → 화면에 경고, 도달 가능한 지점까지만 표시.

## 4. 검증 결과

서울 → 부산 (412.0km, 50%, 20°C, 유효거리 266.1km):

| 순서 | 거리 | 충전소 | 직전 지점서 도달가능? |
|------|------|--------|----------------------|
| 현재(50%) 도달한계 | 106.4km | — | — |
| 1차 | 86.1km | 여주추모공원 | ✅ (≤106.4) |
| 2차 | 270.1km | 군위영천휴게소 | ✅ (≤272.4) |
| 최종 충전 후 도달한계 | 456.4km | — | ✅ ≥ 412.0 (완주가능) |

- **모든 충전소가 직전 지점에서 실제 도달 가능**, 마지막 충전 후 목적지 도달 → `feasible=True`.
- 기존 로직의 "369km 1차 충전(도달 불가)" 결함 해소.

## 5. 충전 커브 기반 DP 시간최적화 (구현됨)

`plan_charging_dp()` — greedy(정지 최소)를 넘어 **총 소요시간(주행+충전+정차) 최소화**.

### 5.1 충전 커브
급속충전 출력은 SoC가 높을수록 급감(taper)한다. BYD 돌핀(LFP) 근사 곡선(SoC%→kW):
`(0,60)(30,58)(50,45)(70,30)(80,20)(90,12)(100,8)`. 실제 충전기 출력과 차량 커브 중 **낮은 값** 적용, 효율 0.9.
→ 고SoC 충전은 매우 느려, **필요한 만큼만 부분충전**하는 것이 시간 최적.

### 5.2 DP 정식화
- **상태** `dp[node][soc]` = 노드에 해당 SoC로 도착하는 최소 시간(분). SoC 5% 버킷.
- **노드**: 출발지 · 후보 충전소(구간별 상위 급속·근접 pruning) · 목적지. 출발/도착 ±2km 후보 제외.
- **전이(all-pairs)**: 노드 i에서 SoC a→d로 충전(커브 기반 시간 + 정차 오버헤드 12분 + 우회) 후, 도달 가능한 임의의 j로 직행. *인접노드 전이는 SoC 이산화 오차가 노드마다 누적되어 폐기함.*
- **목적**: `min dp[목적지][soc≥안전마진]` → 역추적으로 **어느 충전소·몇 %까지** 충전할지 산출.
- **복잡도**: O(노드² × SoC버킷 × 충전량옵션) ≈ 수십만, 실시간.

### 5.3 핵심 파라미터
- 안전마진 10% · SoC버킷 5% · 정차 오버헤드 12분(정지수↔시간 균형) · 충전 효율 0.9
- **정차 오버헤드**가 정지 남발을 막는 핵심 — 없으면 저SoC 고속구간만 조금씩 담으려 정지 폭증.

### 5.4 검증 (서울→부산 412km, 20°C)
| 현충전 | 방식 | 충전 | 예시 | 총 시간 |
|--------|------|------|------|---------|
| 50% | DP | 3회 | 안성휴게소 25→55%, 화서휴게소 10→55%, 영천 10→55% | 426분 |
| 80% | DP | 2회 | 화서·영천 각 10→55% | 397분 |

- **부분충전(→55%)**: 커브 taper를 피해 80%까지 안 채우고 다음 정지 — ABRP식 시간최적 거동.
- 시작 SoC 높을수록 정지 감소. greedy(항상 80%, 정지 최소)와 달리 **총 시간** 최소.
- DP 불가(후보 없음) 시 **greedy로 폴백**(도달가능성 우선).

### 5.5 남은 한계
- 충전 커브는 근사(차종별 실측 커브 데이터 적용 시 정확도↑).
- 평균속도·이탈거리는 경로 전체 근사(구간별 미분화). 고도·실시간 교통 미반영.
- 충전 단가 기반 **비용 최소화**는 미반영(시간만) — 목적함수에 요금 추가로 확장 가능.
