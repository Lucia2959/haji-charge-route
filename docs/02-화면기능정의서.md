## S-02. 메인 화면 (`/main`) — 핵심 화면

### 2.1 영역 구성 (위→아래)

```
┌─ 헤더 ────────────────── [새로고침 아이콘] ─┐  ※ 계획 있을 때만 아이콘 표시
├─ 즐겨찾기 (3칸 그리드) ─────────────────────┤  🏠 / 📍 / ↺초기화
├─ 입력부 ────────────────────────────────────┤  출발지 / 도착지 / 현충전량 / 기온
├─ [충전 계획 계산] 버튼 ─────────────────────┤
├─ 경고 배너 (조건부) ────────────────────────┤  mock경고 / 선충전권장 / 오류
└─ 산출영역 (접이식) ─────────────────────────┘  요약 → 통계 → RouteStrip → 3버튼 → 패널
```

### 2.2 UI 요소 상세

| 요소 | 타입 | 검증 | 동작 |
|---|---|---|---|
| 즐겨찾기 슬롯 ×2 | 버튼 | — | **채워짐**: 탭 → 포커스된 입력칸(`active`)에 주소 입력 / **빔**: 탭 → 장소검색 모달(`shortcut:N`) |
| 즐겨찾기 삭제 | 버튼 (✕) | — | 해당 슬롯 `null` 처리 + localStorage 갱신 |
| 초기화 | 버튼 (↺) | — | 출발/도착/계획 전부 삭제 + `clearAllRouteData()` |
| 출발지 | 버튼(입력처럼) | 비면 계산 버튼 비활성 | 탭 → `active="origin"` + 모달 열기 |
| 도착지 | 버튼(입력처럼) | 비면 계산 버튼 비활성 | 탭 → `active="destination"` + 모달 열기 |
| 현충전량 | `number` | 0~100 (서버 `ge=0, le=100`) | — |
| 기온 | `number` | -40~60 (서버 동일) | 수동 수정 시 `tempAuto=false` |
| 충전 계획 계산 | 버튼 | 출발·도착 필수 | `planRoute()` → `savePlan` + 산출영역 펼침 |
| 새로고침 | 아이콘 버튼 | **8초 쿨다운** | 기온 재조회 → 경로 재계산 |

> **입력 폰트 16px 고정** (`globals.css` → `.input { font-size: 1rem }`).
> 16px 미만이면 iOS Safari가 포커스 시 화면을 강제 확대하고 되돌아오지 않는다.

### 2.3 산출영역 (계획 결과)

접이식(`resultOpen`). 헤더 탭 시 `grid-template-rows: 0fr → 1fr` 300ms 슬라이딩.

> 접힘 상태는 시각적으로만 감추므로, 내부 버튼이 탭 순서·스크린리더에 남지 않도록
> `aria-hidden` + `inert`를 함께 건다.

| 블록 | 내용 |
|---|---|
| 요약 헤더 | 📊 아이콘 + "총거리 · 총소요 · 충전N회" + 셰브론 |
| 통계 3칸 | 총 거리(km) / 총 소요(분) / **충전예상지점수(회, 강조)** |
| 시간 분해 | "주행 N분 + 충전·정차 M분 · 충전커브 시간최적화(DP)" |
| 완주 불가 경고 | `feasible=false`일 때 빨간 배너 (`role="alert"`) |
| **RouteStrip** | 경로 흐름 시각화 (아래 2.4) |
| 액션 3버튼 | 지도보기(이동) / 상세보기(토글) / 산출근거(토글) |
| 상세보기 패널 | 충전소 목록 + 실시간 상태 배지 + 대체 충전소 + 목적지 충전소 |
| 산출근거 패널 | 다크 모노스페이스. 유효거리 계산식·정체 추가소비·도달가능 거리 |
| 참고 고지 | "이 결과는 … 참고 계산입니다" (필수 유지) |

### 2.4 RouteStrip (`components/RouteStrip.tsx`)

```
🚗 출발지     →(−32%, 180km)→   ⚡ 1차        →(−28%, 150km)→   🏁 목적지
   50%                             18→80%                          52%
   0km                             180km                           330km
```

| 노드 | 아이콘 | SoC 배지 | 클릭 |
|---|---|---|---|
| 출발지 | `origin-car.png` | `현충전량%` | — |
| 충전소 | `charger.png` | `도착%→충전%` | 충전소 상세로 이동 |
| 목적지 | `dest-flag.png` | `도착 잔량%` | 목적지 충전소 있으면 상세로 |

- SoC 색상: **≥50% 초록 / ≥20% 주황 / <20% 빨강**
- 목적지 도착 SoC = `마지막 출발SoC − (남은거리 / 유효거리) × 100` (산출근거와 동일 식)
- 지점 3개 이하 → 화면 폭에 균등 배치(`flex-1`), 4개 이상 → 가로 스크롤

### 2.5 조건부 배너

| 배너 | 조건 | 색상 |
|---|---|---|
| mock 경고 | `data_source === "mock"` | 앰버 |
| **출발 전 선충전 권장** | `origin_precharge != null` | 오렌지 + 인근 충전소 버튼 |
| 계산 오류 | `mutation.isError` | 빨강 (`role="alert"`) |
| 새로고침 실패 | `refreshError != null` | 빨강 (`role="alert"`) |

### 2.6 상태 관리

| 상태 | 저장 | 비고 |
|---|---|---|
| `origin`, `destination`, `charge`, `temp`, `tempAuto`, `active` | sessionStorage (`haji.mainForm`) | `hydrated` 이후에만 저장 |
| `plan` | sessionStorage (`haji.routePlan`) | |
| `shortcuts` | localStorage (`haji.shortcuts`) | 개인 주소 |
| `picker`, `resultOpen`, `detailOpen`, `basisOpen` | 메모리 | 화면 상태 |

**마운트 시퀀스**
1. `loadForm()` → 입력 복원, `skipWeather.current = true`
2. `loadPlan()` → 계획 복원
3. `loadShortcuts()` → 즐겨찾기 복원
4. `setHydrated(true)`
5. 복원된 출발·도착이 있으면 `warmupRoute()` **백그라운드 호출** (로딩 오버레이 없음)

**기온 자동조회 (`useEffect [origin.value, hydrated]`)**
- `hydrated` 전에는 조회 안 함
- 복원 직후 1회는 `skipWeather`로 스킵 (복원한 기온을 덮어쓰지 않음)
- 실패 시 기존 값 유지, `cancelled` 플래그로 언마운트 후 setState 방지

### 2.7 새로고침 동작

```
[새로고침] → 8초 쿨다운 시작
  → getCurrentTemperature(origin)   실황 기온 재조회 (실패 시 기존값)
  → planRoute(...)                  경로·교통·충전소 상태 전부 현 시각 기준 재계산
  → 성공: setPlan + savePlan
  → 실패: refreshError 표시 + 쿨다운 즉시 해제 (바로 재시도 가능)
```

## S-05. 충전 계산 (`/charge`)

**진입 조건:** sessionStorage에 `haji.selectedCharger`가 있어야 한다.
없으면 "선택된 충전기가 없습니다" + [충전소로 돌아가기].

| 섹션 | 내용 |
|---|---|
| 선택한 충전기 | 충전소명 · N번 (급속/완속) / 출력 kW / 단가 원 / 배터리 49.92kWh |
| 현충전량 입력 | 숫자 + **단위 토글(% ↔ kWh)** + 환산 힌트 |
| 예상충전량(목표) 입력 | 동일 |
| 결과 | 목표량 / 추가 충전량 / **충전 금액(강조)** / **예상 소요시간(강조)** |
| 참고 고지 | "단순 정출력 기준 계산입니다…" |
| 계산근거 | 다크 모노스페이스, 5줄 수식 |

**계산식 (`lib/charge.ts`)**

```
현충전량 kWh   = 49.92 × 현충전량% / 100
추가 충전량    = max(0, 목표kWh − 현재kWh)
충전 금액      = 추가kWh × 단가(원/kWh)
예상 소요시간  = 추가kWh ÷ 충전기출력(kW) × 60
```

> **이 화면의 계산은 백엔드 DP와 다르다.** 여기는 사용자가 임의 선택한 충전기에 대한
> **단순 정출력** 계산이고, 백엔드 DP는 SoC별 충전커브(taper)를 반영한다. 고SoC
> 구간에서 실제 시간은 이 화면 값보다 길어진다 — 그래서 참고 고지를 붙였다.

**단위 토글:** `switchUnit()`이 같은 물리량을 유지하며 변환한다
(% → kWh는 소수 2자리, kWh → %는 정수).

## M-01. 장소 검색 모달 (`PlaceSearchModal.tsx`)

**호출처:** 메인 화면의 출발지·도착지·즐겨찾기 슬롯

| 요소 | 동작 |
|---|---|
| 오버레이 | 클릭 시 닫기 (`onClick={onClose}`) |
| 다이얼로그 | `role="dialog"` `aria-modal="true"` `aria-labelledby` |
| 닫기 버튼 | ✕ (44×44 터치 타겟) |
| 검색 입력 | `autoFocus`, Enter로 검색 |
| 검색 버튼 | `searchPlaces(query)` |
| 결과 목록 | `aria-live="polite"` 영역. 항목 클릭 → `onSelect(place)` |

**접근성 처리**
- **ESC 닫기** + **포커스 트랩**(Tab/Shift+Tab 순환) + **닫힘 시 이전 포커스 복귀**
- 리스너는 마운트 시 1회만 등록하고 `onClose`는 `ref`로 최신값을 읽는다.
  (부모 리렌더로 포커스가 되돌아가거나 리스너가 재등록되는 것을 방지)

**선택 결과 처리:** 좌표를 `"lng,lat"` 문자열로 만들어 저장한다.

## G-01. 전역 로딩 오버레이 (`LoadingOverlay.tsx`)

**트리거:** `lib/loading.ts`의 전역 카운터. 모든 서버호출을 `withLoading()`으로 감싼다.
단, **워밍업(`warmupRoute`)은 감싸지 않는다** — 사용자가 보는 로딩을 띄우면 안 되므로.

| 요소 | 내용 |
|---|---|
| 배경 | `rgba(240,244,248,0.55)` + `blur(1.5px)`, 터치·스크롤 차단 |
| 로더 | `CarLoader` — 앞/옆/뒤/윗면 SVG를 순차 표시 (순수 CSS 키프레임) |
| 접근성 | `role="status"` `aria-live="polite"` `aria-busy="true"` |

**경과 시간별 안내 문구** — 콜드 상태 계산은 1분 가까이 걸릴 수 있어, 설명이 없으면
멈춘 것처럼 보인다.

| 경과 | 문구 |
|---|---|
| 0s | "불러오는 중…" |
| 4s | "실시간 교통·충전소 상태 조회 중…" |
| 12s | "충전 계획 최적화 중… 처음엔 1분까지 걸릴 수 있어요" |

**깜빡임 방지:** `useGlobalLoading(delayMs = 120)` — 120ms 미만의 짧은 호출은
오버레이를 띄우지 않는다.
`prefers-reduced-motion: reduce`면 애니메이션을 끄고 첫 프레임만 표시한다.

## 부록 A. 디자인 토큰 (`globals.css`)

| 변수 | 값 | 용도 |
|---|---|---|
| `--byd-primary` | `#0a2540` | 브랜드 네이비 (제목·본문 강조) |
| `--byd-accent` | `#00b894` | 그래픽·선 강조 **(흰 글씨 배경으로는 대비 부족)** |
| `--byd-accent-strong` | `#047857` | **흰 글씨를 얹는 배경·작은 텍스트용 (WCAG AA 4.5:1 통과)** |

전역 포커스 표시:
```css
:where(a, button, input, select, textarea, [tabindex]):focus-visible {
  outline: 2px solid var(--byd-accent-strong);
  outline-offset: 2px;
}
```
`:where()`로 특이도를 0으로 만들어, 개별 컴포넌트의 `outline: none`을 덮으면서도
다른 스타일과 충돌하지 않는다.

## 부록 B. PWA 설정

| 파일 | 내용 |
|---|---|
| `app/manifest.ts` | `display: "standalone"`, 아이콘 192/512 + maskable(14% 여백) |
| `app/layout.tsx` | `appleWebApp.capable`, `themeColor: #0a2540`, `viewportFit: "cover"` |
| `globals.css` | `.phone-shell`에 `env(safe-area-inset-*)` 패딩 (노치 대응) |

> `viewport`에서 **`maximumScale`을 의도적으로 제거**했다. 저시력 사용자의 모바일
> 확대를 막지 않기 위함 (WCAG 1.4.4). 대신 입력 폰트를 16px로 올려 iOS의 자동
> 확대를 방지한다.
