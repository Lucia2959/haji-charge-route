# 아이콘은 이라스토야에서 먼저 찾는다

이 프로젝트의 UI 아이콘은 **いらすとや(irasutoya.com)** 무료 일러스트를 우선 사용한다.
인라인 SVG를 새로 그리거나 아이콘 라이브러리를 추가하기 **전에** 반드시 이 사이트를 먼저 검색한다.

## 적용 순서

1. **이라스토야 검색** (아래 워크플로) → 기능·명칭에 맞는 그림이 있으면 사용
2. 적절한 그림이 없을 때만 → 기존 인라인 SVG 방식으로 직접 작성
3. 새 아이콘 npm 패키지는 추가하지 않는다

## 워크플로

### 1) 검색 — 일본어 키워드로

검색 URL: `https://www.irasutoya.com/search?q=<URL인코딩된 일본어>`

WebFetch로 검색 페이지를 열어 게시물 제목·URL 목록을 얻는다. 한국어 기능명 → 일본어 키워드 예시:

| 기능 | 일본어 검색어 |
|---|---|
| 전기차/차량 | 電気自動車, 車 |
| 충전 | 充電, 充電プラグ |
| 지도/위치 | マップピン, 地図, カーナビ |
| 검색/상세 | 虫眼鏡, 検索 |
| 계산 | 電卓, 計算 |
| 목적지/완주 | チェッカーフラッグ, ゴール |
| 날씨/기온 | 天気, 温度計 |
| 경고/주의 | 注意, 警告 |
| 설정 | 設定, 歯車 |

**버튼용 아이콘은 사물 단독 그림을 고른다.** "○○を持つ人"(사람이 들고 있는) 류는 작은 버튼에서 뭉개지므로 피한다.

**나란히 놓이는 아이콘끼리 의미가 겹치지 않게 한다.** 예: 출발지에 "電気自動車"(충전기까지 그려진 EV)를 쓰면 옆의 충전소 아이콘과 헷갈린다 → 차량 단독 그림을 쓴다.

### 2) 이미지 URL 추출

검색 결과의 게시물 페이지를 WebFetch로 열어 `blogger.googleusercontent.com/.../s800/<파일명>.png` 형태의 직접 URL을 얻는다.

### 3) 다운로드 + 최적화 (필수)

원본은 800px·수백 KB라 **모바일 웹앱에 그대로 쓰면 안 된다.** 반드시 여백 제거·리사이즈·압축한다.

```js
// node 스크립트 (sharp는 이미 설치돼 있음)
const sharp = require('<프로젝트>/frontend/node_modules/sharp');
await sharp(src)
  .trim({ threshold: 10 })                 // 투명 여백 제거 → 작은 박스에서도 꽉 차게
  .resize(96, 96, { fit: 'contain', background: { r:0,g:0,b:0,alpha:0 } })
  .png({ compressionLevel: 9 })
  .toFile('frontend/public/icons/<용도>.png');
```

- 저장 위치: `frontend/public/icons/<용도>.png` (파일명은 **용도 기준** — `map.png`, `charger.png`처럼)
- 목표 크기: 개당 5KB 이하 (실적: 6개 36KB)

### 4) 코드 반영

`next/image`로 참조하고, 주석에 **출처와 원본 일본어 명칭**을 남긴다.

```tsx
// 충전소 — EV 충전 플러그(電気自動車の充電プラグ) · いらすとや
function ChargerIcon() {
  return <Image src="/icons/charger.png" alt="" width={34} height={34} aria-hidden />;
}
```

- 장식용 아이콘은 `alt=""` + `aria-hidden` (라벨 텍스트가 옆에 있으므로 중복 낭독 방지)
- 버튼에 색상 반전(active) 상태가 있어도 PNG는 색이 안 바뀐다 — 배경 대비만 확인

## 라이선스 (지켜야 할 선)

- 개인·상업 이용 모두 무료. 단 **한 프로젝트당 20점까지** (21점 이상은 유료 라이선스)
- 현재 이 프로젝트 사용량: **6점** (origin-car, charger, dest-flag, map, detail, calc)
- **금지**: 일러스트 자체를 주된 콘텐츠로 하는 재배포·판매, 혐오·차별·성적 용도
- 저작권은 제작자에게 있음 (편집·가공은 허용)

새 아이콘을 추가할 때는 위 사용량을 갱신하고, 20점에 근접하면 사용자에게 알린다.

## 현재 적용된 아이콘

| 파일 | 용도 | 이라스토야 원본 |
|---|---|---|

| `charger.png` | 경로 스트립 충전소 | 電気自動車の充電プラグのイラスト |
| `dest-flag.png` | 경로 스트립 목적지 | チェッカーフラッグのイラスト |
| `map.png` | 지도보기 버튼 | マップピンのイラスト |
| `detail.png` | 상세보기 버튼 | 検索虫眼鏡のイラスト「Search」 |
| `calc.png` | 산출근거 버튼 | 正面から見た電卓のイラスト（小） |
